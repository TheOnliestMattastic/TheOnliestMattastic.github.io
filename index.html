StatelessIO — Edge-Deployed Developer Micro-Utilities

StatlessIO is a lightweight, stateless suite of developer APIs deployed on Cloudflare Workers and distributed through RapidAPI.

Modules

  • ShiftFS: A serverless path and payload manipulation engine. Handels structure transformations, path formatting, and string normalization at the edge without requiring server-side disk access.
  • NullTrace: A data-scrubbing filter. Intercepts incoming payloads and strips sensitive metadata, personal identifiers, and log noise before data touches downstream storage or analytics.

Features

  • Zero State Overhead: Eliminates database dependencies and session persistent storage entirely.
  • Low Latency: Executed directly at the network edge via Cloudflare Workers.
  • Modularity: Isolated JavaScript micro-functions designed to be plugged straight into existing automation or pipeline workflows without bloat.
  • Built with: JavaScript · Node.js · Cloudflare Workers · RapidAPI
